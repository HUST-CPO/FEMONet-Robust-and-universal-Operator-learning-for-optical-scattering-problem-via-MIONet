## Why files are missing from the repository

`Train_data_B1_*.mat`, `deepOnet_data_B1_*.mat`, and `E_*_pred_50688*.mat` are **not included** because each file is **very large** (multi‑GB COMSOL sampling and 50k+ sample tensors). Only the small split file `idx_B1_50688.mat` is kept so the deepOnet / training pipeline can be reproduced once `Train_data` is generated locally.

2. `data_read_Ez_B1_50688.m` using **`idx_B1_50688.mat`** → `deepOnet_data_B1_50688.mat`
