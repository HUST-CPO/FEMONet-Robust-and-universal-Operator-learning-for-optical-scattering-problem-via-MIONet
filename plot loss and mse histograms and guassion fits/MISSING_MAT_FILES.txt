# Plotting module — missing data files
# Scripts: compute_mse_cache.m, run_all_mse_histograms.m
# Case mat_data paths: <case>/samples and post proceeding/mat_data/

## Why files are omitted from the repository

Large `.mat` files (`Train_data_*.mat`, `deepOnet_data_*.mat`, `E_*_pred*.mat`) are **not committed** because each can occupy **hundreds of MB to several GB**, exceeding practical GitHub limits. Smaller split files (`idx_*.mat`) and compact case subsets are included when possible.

Loss-curve plotting uses only text logs in `loss_log/` and does **not** need `.mat` files.

MSE histograms need ground-truth + prediction `.mat` files from each case’s `mat_data/` (see per-case `MISSING_MAT_FILES.txt` for how to generate them).
