## Recommended order

1. `Main_Scattering_C_cnn.m` → `Train_data_C_3456.mat`
2. `data_read_Ez_C_3456.m` → `deepOnet_data_C_3456.mat` + `idx_C_3456.mat`  
   (`idx_C_3456.mat` is already in the repo; skip re-split if you use the same file.)
3. `python NN/cnn_branch_test_1.py` → `E_*_pred_size_3456.mat`
4. `outputE_v2.m` → `pdf_results/`

**Shortcut if you only need training:** with `idx_C_3456.mat` from the repo, run step 1 then step 2 to recreate `deepOnet_data_C_3456.mat` locally.

MSE histogram (`compute_mse_cache('C')`) needs **all** of: `Train_data`, `deepOnet`, `idx`, `E_train/test_pred`.

Copy training log to `plot loss …/loss_log/modelC_loss.txt` for loss curves.
