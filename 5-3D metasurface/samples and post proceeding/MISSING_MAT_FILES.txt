## Why files are missing from the repository

3D datasets use **MATLAB v7.3 (HDF5)** `.mat` files that are often **1–10+ GB**. GitHub rejects any single file **> 100 MB**.

| File | Approx. size | GitHub status |
|------|--------------|---------------|
| `deepOnet_data_3Dcase3_261.mat` | **~851 MB** | **Excluded** (listed in root `.gitignore`) |
| `Train_data_3Dcase3_521.mat` | multi-GB | Not included |
| `Train_data_3Dcase3_261.mat` | large | Not included |
