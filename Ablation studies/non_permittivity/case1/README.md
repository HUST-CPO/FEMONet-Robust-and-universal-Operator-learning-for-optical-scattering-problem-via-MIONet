# Permittivity-input reference: case1

Run `python cnn_branch_test1.py` from this directory. The supplied MAT file contains the training and test arrays used by the loader. Use `--data` to select another prepared dataset. Training settings are defined in `PINNConfig`; predictions and checkpoints are written to the working directory.

To plot a saved training log, run `python img.py --log training.log`.
