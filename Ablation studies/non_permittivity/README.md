# Permittivity-input reference cases

Three additional reference configurations retain their supplied networks and FEM residuals. Each directory contains its matching prepared data and a training entry point. Case 1 uses A1_847, Case 2 uses B1_847, and Case 3 uses C1_3388. Run `python assemble_data.py` here before Case 3, then follow each case README. MAT compression preserves the stored arrays.
